# Fonts in this directory

Both files are redistributed here under the SIL Open Font License 1.1, which
requires the licence to travel with the font. They are embedded as base64 into
the OG image routes rather than fetched at runtime, because Satori's remote
image and font fetching does not work reliably under Cloudflare Workers.

- **InstrumentSerif-Regular.woff**: Instrument Serif, by Rodrigo Fuenzalida
  and Jordan Egstad. https://github.com/Instrument/instrument-serif
- **IBMPlexMono-Regular.woff**: IBM Plex Mono, by IBM.
  https://github.com/IBM/plex

The full licence text is available at https://openfontlicense.org and in each
upstream repository above. Both are used unmodified.
